# Аудит Polka · 2026-10-11

Проверен frontend, backend, SQL, storage, auth, публичность, импорт/экспорт, Compose, CI/CD и Kubernetes. Три сабагента с effort `high` выполняли frontend-работу, backend-работу и независимый аудит; родитель интегрировал изменения и проверяет локальный runtime. Production не изменялся.

## Зависимости Go

`govulncheck` выявил 10 статически достижимых advisory в пяти модулях; это не означает, что все десять атаки воспроизводятся в текущей конфигурации. Обновлены `x/image` 0.45.0, `x/text` 0.41.0, pgx 5.9.2, chi 5.3.0, S3 SDK 1.97.3 / eventstream 1.7.8. Особенно важен принимающий пользовательские данные WebP decoder: [GO-2026-6222](https://pkg.go.dev/vuln/GO-2026-6222). Для pgx [advisory требует специальных условий simple protocol](https://pkg.go.dev/vuln/GO-2026-5004); наличие уязвимой версии не доказывало SQL injection в Polka. Runtime и CI переведены на Go 1.27, контейнерные builders закреплены на 1.27.2. Проверка: `npm run audit:backend`.

## UI и контент

Сохранена редакционная стилистика. Доработаны устойчивые размеры обложек, hover/focus, появление карточек, sticky shelf rail, горизонтальная навигация, пустые/error состояния и keyboard focus. Затемнены яркие gradient controls для читаемости белого текста. На публичных/owner/auth/form/book/list экранах проверяется отсутствие горизонтального overflow при 360/768/1440px. Скриншоты дополнительно сняты при 390px.

Добавлены восемь карточек на четырёх языках, оригинальные SVG/PNG обложки, заметки и две подборки. Источники и воспроизводимые команды — в [demo-content.md](demo-content.md).

## Проверки

- Frontend unit: 47 тестов, 8 suites — прошли на Node 22.
- Playwright: 12 сценариев — прошли в установленном Chrome, включая приватные cover/book/list, rejected import, owner CRUD, keyboard и reduced motion.
- Backend: `go test ./...` с отдельной PostgreSQL БД — прошёл; SQL integration выполнялся, не был пропущен.
- ESLint/Stylelint, format, `go vet` и race detector прошли. Production frontend build укладывается в неизменённый 8kB style limit (остаются 4kB warning thresholds). Все четыре Compose services работают на новых образах. Health 200 напрямую и через Nginx; Playwright выполнен на production frontend. Volumes сохранены. На этой машине отсутствие Buildx вызывало classic builder fallback; два layer export сбоя устранены запуском BuildKit, без restart/prune общей Colima.
- `govulncheck`: 0 vulnerabilities в вызываемом коде и imported packages; 19 advisories в required modules без обнаруженного вызываемого пути.
- `npm audit --omit=dev`: 0 vulnerabilities после patched Angular и точечного minimatch override.

## Оставшиеся ограничения

- Полный npm audit сохраняет 33 findings (21 moderate, 12 high) в dev tooling; критических нет. В частности, для цепочки `braces`/Stylelint опубликованного совместимого исправления нет. Не применяется `audit fix --force`, предлагающий несовместимые downgrades. Это не утверждение об эксплуатируемости этих цепочек в приложении. Angular исправлен по [официальному advisory](https://github.com/advisories/GHSA-hh8m-fm6v-7cvg).
- MinIO upstream [архивирован](https://github.com/minio/minio); source build восстанавливает воспроизводимость, но не обещает будущих security updates. Для production нужен выбор поддерживаемого S3-provider.
- Уже существующая известная demo-учётка и старые sudo-строки в истории Git не исчезают от изменения кода. Смена реальных совпадающих credentials — отдельная административная операция.
- Одновременные attach/delete одного cover тем же владельцем требуют более строгого media lifecycle. Чужие ключи запрещены, используемые объекты сохраняются.
- Загруженная обложка в несохранённой форме не переживает reload; текстовый черновик сохраняется. Автоматический сбор неиспользованных загрузок остаётся следующим шагом.
- Нет ручной проверки Safari/Firefox, screen reader или физического мобильного устройства. Chromium viewport tests не подтверждают все браузеры.
- Это полный обзор текущего репозитория и воспроизведённых локальных сценариев, а не гарантия отсутствия всех возможных дефектов.
